# Layout fragment: phase_trigger (trigger path, line driver, 16-tap phase delay line) - re-layout
`python3 gen_phase_trigger.py` -> `phase_trigger.kicad_pcb` (KiCad 7, 105.1 x 25.4 mm, own Edge.Cuts) and prints all tables and checks below.
`phase_trigger.png`: top = F.Cu without the pour (so widths show), silk, fab; below: F.Cu with pour, B.Cu (mirrored), In1, In2.
`phase_trigger_detail.png`: tap cells and one comparator, F.Cu red and B.Cu blue. Values: `sim/phase`, `sim/phase_array` RESULT.md, SPEC 4-6, 9.

## Stack-up (SPEC decision 9 rev., written into the board setup)
JLC04161H-7628 1.6 mm, checked on jlcpcb.com/impedance: F.Cu 35 um / 7628 0.2104 mm er 4.4 / In1 = solid GND / core 1.065 mm /
In2 = power (+2V5, +3V3, VTAP_N / VTAP_P strips) / 7628 0.2104 mm / B.Cu (GND pour, -2V5 and VSW_GND polygons, slow nets).
Mask er 3.8, 15 um on the trace. `microstrip()` = Hammerstad-Jensen + thickness correction + first-order mask term; `cpwg()` = Wadell.
| Line | width | Z0 | eps_eff | delay |
|---|---|---|---|---|
| 50 R (all 50 R nets, feeds, terminations) | **0.36 mm** (exact 0.360) | 50.0 R (51.0 R without mask) | 3.30 | 6.057 ps/mm |
| PSTRB_A/K sections, 73 R | **0.16 mm** (exact 0.159) | 72.8 R | 3.08 | 5.852 ps/mm |
| PH_LINE sections (width chosen for loaded 50 R) | **0.25 mm** (exact 0.251) | 60.1 R | 3.19 | 5.959 ps/mm |
Coplanar check: the side pour only lowers Z for gaps < 0.33 mm; pour gap used = 2 w (0.72 / 0.32 / 0.50 mm) -> microstrip, no correction.
Top pour keep-outs at 2 w around every RF segment and pad (script-verified on the filled pour); no pour between the strobe lines.
## Delay line (every cell generated by the same code, spread 0.000 ps)
| line | section | Z0 | load / tap | length / tap | unloaded | loaded | loaded Z |
|---|---|---|---|---|---|---|---|
| PSTRB_A/K | 0.16 mm straight | 72.8 R | 0.40 gate + 0.049 cap pad + 0.02 resistor fringe = 0.469 pF | **4.514 mm = pitch** | 26.4 ps | **40.0 ps** | 48.1 R |
| PH_LINE | 0.26 mm S-meander | 59.0 R | 0.37 gate + 0.026 pin-3 pad = 0.396 pF | **9.929 mm** | 59.3 ps | **70.0 ps** | 50.0 R |
PH_LINE targets 70 ps and the strobe lines 40 ps per tap (phase_array/RESULT: a 70 ps design measured 75.7 ps) -> expected ~75 ps real, 35 ps effective. The per-tap delays were raised from 65 / 35 ps so that the pitch (4.514 mm) leaves room for the meander: pin-3 pad edge to the nearest meander leg 0.52 mm, leg to leg 0.51 mm (was 0.02 / 0.244 mm). The 40 / 75 ps combination is not re-simulated.
Note: for a 70 ps section the trace that loads to 50 R is 60 R, not 73 R (73 R belonged to the 24 ps sections of phase/RESULT).
Cell: BAT15-04W, PH_LINE enters between pins 1/2 under the body and ends in pin 3 (zero-length tap), leaves pin 3 downward into an
S-meander (legs x = 1.00 / 1.99 / 2.76 mm, half-height 1.50 mm, same-net gaps >= 0.5 mm), 45-degree landing into the next diode. All on F.Cu
over In1, **no vias in any RF path**. Hold caps CA/CK vertical, node pad 0.29 mm from pin 1/2 (0.15 mm node trace), outer pad on the
strobe line. 1 k (to the comparator) and 2.2 k (to VTAP via In2) straddle each strobe line, perpendicular, either side of the cap.
**Summing node (symmetric)**: the A-side and K-side 1 k resistors are mirror images; each outer pad has a via (0.605 mm F.Cu) and the two
vias are joined by a straight B.Cu jumper (2 x 3.835 mm). The comparator input is tapped from the jumper MIDPOINT: a B.Cu branch runs
0.8 mm west of the jumper to its own via (4.166 mm), then F.Cu to the comparator pin. Both resistors therefore see the same path and stray
capacitance. Each COS3502 is centred between its two tap vias, so the routes to pins 1 and 3 are mirror images (3.849 mm each); the
script asserts channel A = channel B. One extra via per tap.
In1 cut-out under each hold node (VTAP strip in In2 below instead, symmetric A/K). K-side 1 k joins the A side on B.Cu (DC node).
COS3502 row behind PSTRB_A: pin 1 in line with the tap's 1 k, IN- via to the B.Cu VTH rail (R404 1 k / C404 100 n from VTAP_TH).

## Main chain (y = 0, in line, 0.3-0.35 mm pad gaps)
X1 BUF_OUT_T / J301 SMA (49.9 R R301 at U301.3) -> U301 TMUX136 -> TRIG_COM 3.0 mm -> U302 TLV3801 -> CMP_P / CMP_N as 2 x 50 R
(0.6 mm gap), R307 100 R bridging, R309/R310 470 R taps (LVDS_A under CMP_N on B.Cu) -> C308 -> U303 TRF37D73 -> L301 120 n
(T on the line) / L302 47 u -> C309 -> pi pad R311/R312/R313 -> 0.36 -> 0.25 mm step at x = -1.6 -> D01. PSTRB feeds from X2/X3
(50 R, 3.84 mm) step to 0.16 mm half a pitch before tap 0; far end 0.36 mm into 49.9 R (R401, R402, R403).
Necks: none (0.36 mm traces end on the WSON/UQFN pin centres with >= 0.19 mm to the neighbour pins).
Pad discontinuities (excess C vs line): 0402 in-line / T pads +28 fF, WSON/UQFN pins -11 fF, SOT-323 pin 3 +28 fF and hold-cap
pad +49 fF (both inside the tap load). SMA pin (1.27 mm): In1 cut-out below -> 70 R over 1.8 mm instead of +314 fF.

## Supplies and vias
Each supply pin -> 0.25-0.6 mm copper -> decoupling cap at the pin -> via pair to the In2 plane; -2V5 (TLV EP vias, R304, R306)
and VSW_GND (TMUX) as B.Cu polygons, VSW_GND pins also on a local F.Cu polygon; TRF EP 3 vias. Ground pads: one via beside
the pad. 167 vias: 47 GND, 69 supply, 51 signal (TAPn_IN, VTH, LVDS_A); **no stitching grid, no fences** (stitch after assembly).

**Changed vs previous**: JLC04161H-3313 -> 7628; all widths from the formula; PH_LINE moved from B.Cu (2 vias per tap) to an F.Cu meander; strobe 0.09 ->
0.16 mm (73 R now possible), pitch 3.815 -> 4.514 mm (40 ps per tap); compact in-line chain; no 90-degree corners; power via planes/polygons;
588 stitching vias removed; outline 106.8 x 24.6 -> 105.1 x 25.4 mm.

## Checks and open points
Script: bends <= 45 deg everywhere (corners at pad centres excepted), 0.1 mm copper clearance OK, passive courtyards OK, own
connectivity check 0 unrouted, RF pour clearance OK. 21 decoupling/chain parts sit inside the IC courtyard margin (pad gap >= 0.25 mm).
**kicad-cli 7 has no DRC**: run DRC in pcbnew after integration. U301 COM2 open on purpose.
Open: 40 / 75 ps per tap is not re-simulated (sim/phase_array used 35 / 70 ps); meander self-coupling is small at 0.5 mm gaps (2.4 h) but check by TDR.
Loaded strobe Z 45.5 R vs 49.9 R terminations (5 % reflection). Left 1 k inner pad of each node is over ground (~0.06 pF).
VTAP decoupling only at both ends of the In2 strips (DC rail behind 2.2 k). Corner WSON pins entered along x, not the pad axis.

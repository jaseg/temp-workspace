# Layout fragment: phase_trigger (trigger path, line driver, 16-tap phase delay line)
`python3 gen_phase_trigger.py` -> `phase_trigger.kicad_pcb` (KiCad 7, 106.8 x 24.6 mm, own Edge.Cuts), delay table, checks.
`phase_trigger.png`: F.Cu (red) / B.Cu (blue) / silk / fab, zones hidden so the routing shows (the .kicad_pcb has them filled).
Values: `sim/phase/RESULT.md`, SPEC decisions 4-6, 9. Net names: SPEC / `kicad/gen/gen_trigger_phase.py`.

## Stack-up and line geometry (in the board setup)
JLC04161H-3313: F.Cu / 0.0994 mm 3313 (er 4.1) / In1 = solid GND / 1.265 mm core / In2 = power planes / 0.0994 mm / B.Cu.
Hammerstad-Jensen + Wheeler thickness correction: 50 R = 0.172 mm, drawn **0.17 mm (50.4 R, 5.87 ps/mm)**.
- **Strobe lines PSTRB_A/K** (F.Cu over In1): 0.09 mm = 67.3 R, 5.74 ps/mm (73 R would need 0.07 mm, below the JLC minimum).
  Load per tap 0.40 pF (gate) + 0.106 pF (hold-cap pad on the line) = 0.506 pF. Loaded delay sqrt(tdu(tdu+Z*C)) = 35 ps
  -> tdu 21.9 ps -> **pitch 3.815 mm** (RESULT gave ~3.5 mm on another stack-up). Loaded Z = 42 R.
- **PH_LINE** (signal) on **B.Cu over In2, which is a GND zone under the whole delay line**: 0.10 mm = 64.5 R. Load 0.37 pF
  (gate) + 0.089 pF (pin-3 pad) per tap; 2 vias per tap counted as 1.53 mm sections in FR4 (10.7 ps each). 70 ps loaded
  -> 6.136 mm of trace per tap -> B.Cu U of 1.34 mm depth between taps. Loaded Z = 52.3 R.
- Achieved (script table): all 15 intervals **35.00 / 35.00 / 70.00 ps (A / K / line), effective 35.00 ps, spread 0.000 ps**:
  every tap cell is generated by the same loop code with identical relative geometry.

## Placement
Left to right on the y = 0 axis: X1 BUF_OUT_T / J301 EXT_CLK SMA (49.9 R at U301.3) -> U301 TMUX136 (KiCad
Texas_UQFN-10_1.5x2mm = TI RSE0010A land pattern; A2/B2/EN/GND on VSW_GND = -0.9 V from 1.5 k / 2.7 k, 100 n + 1 n;
SEL via 10 k / 18 k) -> U302 TLV3801 (WSON-8 DSG, EP = VEE, 100 n per rail, 10 n on IN-) -> R307 100 R at the outputs
-> CMP_N: 1 uF + 49.9 R dummy; 2 x 470 R -> U304 SN65LVDS2 -> COARSE (LVDS_B crosses CMP_P on B.Cu, slow path) ->
CMP_P: 1 uF -> U303 TRF37D73 (120 nH + 47 uH 1008 choke, 1 n + 100 n both ends, EP vias) -> 1 uF -> 82/91/82 pad ->
via -> PH_LINE on B.Cu. Strobes enter at X2 (PSTRB_A, top) / X3 (PSTRB_K, bottom), mirror images, 6.44 mm each.
Tap cell (pitch 3.815 mm, D01..D16): BAT15-04W, pin 3 on PH_LINE (V_in/V_out vias either side of pin 3, under the body);
0.47 pF C0G from the A node up onto PSTRB_A and from the K node down onto PSTRB_K (line runs through the cap pad);
2.2 k and 1 k straddle the strobe line (line passes between their pads); 2.2 k ends on the F.Cu VTAP_N / VTAP_P rails,
the two 1 k join as TAPn_IN on B.Cu between the line vias and go up to the COS3502 (SOIC-8, COS3502SR = SOP-8, Cosine
pinout from the schematic), IN- = VTH (B.Cu rail under the comparators, R404 1 k + C404 100 n from VTAP_TH).
**In1 cut-outs under every hold node** (diode pins 1/2, node bus, cap/resistor node pads); In2 GND stays (shields PH_LINE).
Far end: 49.9 R on PSTRB_A, PSTRB_K, PH_LINE. 100 nF on each VTAP rail every two taps, 100 nF at each COS3502.
588 GND vias: stitching beside every RF line (~0.9 mm pitch) plus a 1.5 mm grid.

## Checks and open points
Script: no courtyard overlaps, no copper pair of different nets closer than 0.1 mm (pcbnew shape collisions): OK.
**kicad-cli 7 has no DRC**: run DRC in pcbnew after integration. U301 COM2 is left open on purpose.
Open: strobe line loaded Z is 42 R (0.09 mm minimum width) against 49.9 R terminations (9 % reflection); the via delay
model and the 0.4 / 0.37 pF loads set pitch and meander and must be checked (TDR or code density); vias in the line
are assumed ~line impedance. TAPn_IN runs 0.65 mm from the B.Cu line legs (estimated < 1 mV feed-through).
